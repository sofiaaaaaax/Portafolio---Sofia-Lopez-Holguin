# Portafolio profesional — Sofi

Sitio web frontend responsive para el parcial de Desarrollo Web. Construido con HTML, CSS y Bootstrap 5.

## Archivos
- `index.html`: estructura y contenido del portafolio.
- `styles.css`: estilos personalizados y adaptación responsive.
- `script.js`: comportamiento pequeño del menú móvil.

## Cómo verlo localmente
1. Descarga o descomprime la carpeta.
2. Abre `index.html` en un navegador. Se necesita conexión a internet para cargar Bootstrap, Bootstrap Icons y Google Fonts desde sus CDN.

## Antes de entregar
1. En `index.html`, reemplaza `TU_CORREO@EJEMPLO.COM` por tu correo real.
2. Cambia los enlaces de LinkedIn y GitHub por los tuyos.
3. Revisa que el nombre, instituciones y fechas estén correctos según tus certificados.
4. Si ya tienes proyectos académicos, reemplaza las tarjetas provisionales por proyectos reales.
5. Revisa el sitio en móvil, tableta y escritorio.

## Publicar en GitHub Pages
1. Crea un repositorio público en GitHub, por ejemplo `portafolio-profesional`.
2. Sube `index.html`, `styles.css`, `script.js` y `README.md` a la raíz del repositorio.
3. Entra en **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Elige la rama `main` y la carpeta `/ (root)`, luego pulsa **Save**.
6. Espera a que GitHub Pages publique el sitio. Copia el enlace que aparece en esa sección.

## Framework responsive
Este proyecto usa Bootstrap 5.3.3 mediante CDN y una grilla `container` / `row` / `col-*` con puntos de quiebre para móvil, tableta y escritorio.
